## Major safeguards

- Matched rows must use independent, validated identifiers. Scientific pairing is never proven by code alone.
- `temporal_rsa(..., blocks=...)` restricts null permutations within declared blocks, uses absolute max-statistics across time, and requires an exchangeability argument.
- CCA, Procrustes and shared/private predictive evaluation can hold out groups rather than letting repeated measurements leak across folds. Scaling and PCA are fitted using training data only.
- RSA is **descriptive**; it must not be described as cross-validated just because the CCA API uses folds.
- Procrustes is an orthogonal mathematical rotation/reflection, not anatomical or biological equivalence.
- A temporal peak is not proof of signal transmission direction or delay, especially when comparing fMRI to electrophysiology.

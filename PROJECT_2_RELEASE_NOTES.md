# Release notes — Neuro Multimodal Alignment 0.5.0

Neuro Multimodal Alignment (NMA) is a Python package for comparing representations from matched experimental observations. It is maintained separately from the Neural State Space Lab package.

## Methods included

- Representational dissimilarity matrices and descriptive RSA.
- CCA with training-only scaling and optional dimensionality reduction, evaluated on held-out data.
- Orthogonal Procrustes alignment, with held-out and group-aware evaluation options.
- Model-dependent shared and modality-specific predictive structure.
- Time-resolved RSA and within-block permutation controls, subject to stated exchangeability assumptions.
- Synthetic benchmarks with known shared factors, independent data, selection and overfitting scenarios.

## Validation recorded for this release

The initial archive contained 34 passing tests. The revised source reported 49 local passing tests and 93% statement coverage. Three synthetic scripts and three synthetic notebooks ran locally. Eight figures (four PNG and four SVG) were generated by `reproduce/make_figures.py`.

The published repository also has successful GitHub Actions runs for cross-platform tests, Python linting and package builds. The [Actions history](https://github.com/lathushanrk-cmd/neuro-multimodal-alignment/actions) gives the status of individual commits.

## Boundaries

The optional MNE EEG/MEG example has not been independently verified on downloaded recordings. Matching identifiers and exchangeability assumptions must still be justified by the investigator. The simulations and unit tests are not biological validation, and no DOI, clinical use or peer-reviewed empirical finding is claimed.

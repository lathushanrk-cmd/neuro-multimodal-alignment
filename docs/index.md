# Methods and documentation

Neuro Multimodal Alignment compares the relationships among matched experimental observations recorded or represented in different modalities.

Start with [data matching](data_alignment.md), then choose the method appropriate for the question. Each method imposes different assumptions about feature spaces, sampling and independence.

| Coordinate alignment | [Procrustes](procrustes.md) |

Synthetic examples are included so that key properties can be checked against a known model. The optional real-data workflow is supplied separately and has not been independently verified on downloaded recordings.

# Optional public EEG+MEG demonstration

The script `examples/04_mne_eeg_meg_demo.py` is an optional adapter for the **MNE sample auditory/visual EEG+MEG** data. Despite the historical filename, it does **not** load OpenNeuro data and is not represented as an OpenNeuro demonstration. The sample dataset is relatively large and requires user-directed downloading according to MNE's current official instructions: https://mne.tools/stable/overview/datasets_index.html . It is not included in the ZIP. 

The adapter uses matched event epochs from a single session, selects EEG and magnetometer sensor readings, computes a simple averaged post-stimulus feature representation for each event, and prints **descriptive** RSA. This is not an unbiased across-subject result. Head-to-head distances are sensitive to sensor scales, participant noise, condition composition and trial dependencies. The file has not been run on the downloaded external data in the packaged environment; run and inspect its outputs before citing empirical results. No real-data numerical results or validation are claimed. If exact MNE sample paths, event codes or preprocessing change in future versions, adapt and validate them against the official dataset documentation.

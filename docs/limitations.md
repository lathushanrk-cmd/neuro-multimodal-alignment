# Scientific limitations

- Statistical agreement between modalities does not prove the same underlying neural mechanism.
- RSA is descriptive and is not cross-validated by default.
- CCA can overfit high-dimensional small-sample data; held-out estimates are more informative but are not universal proof of generalization.
- Procrustes aligns mathematical coordinates, not anatomical structures or biological sources.
- Shared/private linear predictability is model-dependent, not the true biological portion of shared information.
- The program checks ID format and order but cannot prove the scientist matched the correct stimuli/participants.
- Grouped cross-validation and blocked permutation still require valid experimental independence and exchangeability assumptions.
- Temporal similarity peaks cannot by themselves identify propagation, causation or fMRI hemodynamic delays.
- All included figures are synthetic computations, not real EEG/MEG/fMRI findings.
- Optional external MNE EEG+MEG data have not been independently run or reported in this release.
- This toolkit is not a medical or clinical diagnosis system and is not independently biologically validated.
